## 🛠️ Run Locally

### Requirements

- Any modern web browser
- Git (optional)

### Clone the repository

```bash
git clone https://github.com/lg-arch252/personal_website.git
cd personal_website
```
### Open the website
Simply open `index.html` in your browser.
Or use VS Code Live Server:
```bash
code .
```
Then start Live Server.
## 🔍 How It Works

This website is built using HTML and CSS and is hosted on GitHub Pages.

The goal of this project was to learn the fundamentals of web development while creating a personal space on the internet. The website focuses on simplicity, readability, and fast loading times rather than complex frameworks or heavy dependencies.

By keeping the project lightweight and static, it can be deployed easily through GitHub Pages without requiring a backend server or database.
